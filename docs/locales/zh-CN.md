## 🧭 关于我

我专注于实时数字音频系统的设计、测量与性能极限优化。我的工作核心是低延迟音频处理流水线：在音频渲染线程中严格禁止任何动态内存分配，确保纳秒级的确定性时序无懈可击。

- 🎛️ **核心研究方向**: 实时物理建模合成、模拟滤波器拓扑仿真、SIMD 向量化加速 DSP 内核。
- ⚙️ **硬件工程**: 基于 STM32H7 与 Raspberry Pi RP2040 微控制器的裸机（Bare-Metal）音频系统开发。
- 📐 **工程信念**: 在核心计算循环（Hot Loop）中贯彻无锁（Lock-Free）与零动态分配（Zero-Allocation）。音频卡顿与缓冲区下溢（xruns）是必须彻底根治的硬缺陷，而非不可避免的妥协。
- ☕ **屏幕之外的生活**: 收藏 20 世纪 70 年代的开盘式磁带录音机、精密校准开盘磁带机械结构、设计分立式模拟前级放大电路。

## 🚀 核心开源项目

### 1. `resonant-core` (C++20 / SIMD / CLAP)
专为确定性实时音频处理设计的模块化、纯头文件 DSP 算法库。
- 实现了 4 倍/8 倍多相过采样滤波器及非线性模拟梯形滤波器拓扑。
- 采用原生 AVX2 和 ARM NEON 内建函数加速，处理块内部实现绝对的零内存分配。
- 基准性能: 在 AMD Zen 4 架构上，每 64 采样点块的处理耗时仅为 0.18 微秒。

### 2. `reel-flutter` (Rust / WebAssembly / VST3)
磁带磁饱和特性与绞盘电机机械抖动（Flutter）的连续时间仿真器。
- 基于四阶龙格-库塔（RK4）常微分方程求解器，对磁带磁芯的磁滞回线进行物理建模。
- 支持交叉编译至 WebAssembly，实现无需安装即可在浏览器中体验声学仿真。

### 3. `rp-mpe-engine` (Embedded Rust / RP2040)
完全支持 MIDI 复音表情（MPE）的自研硬件裸机合成器固件。
- 双核协同架构: 核心 0 专门处理 USB/DIN-MIDI 数据包解析，核心 1 负责运行 48kHz / 16 复音减法合成引擎。
- 彻底移除 RTOS 开销，通过 DMA 直接向立体声 24 位 I2S DAC 进行流式传输。

### 4. `ascii-spectrogram` (C99 / 终端 CLI)
在终端中以 ANSI 全彩色实时呈现 60 FPS 音频瀑布图的高性能命令行工具。
- 具备无锁环形缓冲区，可直接接入 ALSA、PulseAudio、PipeWire、CoreAudio 原生音频流。
- 汉宁窗（Hann）、布莱克曼-哈里斯窗（Blackman-Harris）等加窗函数完全通过 SIMD 指令并行加速。
