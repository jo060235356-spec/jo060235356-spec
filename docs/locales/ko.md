## 🧭 소개

실시간 디지털 오디오 시스템을 설계하고 측정하며 최적화합니다. 오디오 렌더링 스레드 내부에서의 동적 메모리 할당을 엄격히 배제하고, 나노초 단위의 결정론적 타이밍을 보장하는 초저지연 파이프라인 구축에 집중하고 있습니다.

- 🎛️ **주요 전문 분야**: 실시간 물리 모델링 합성, 아날로그 필터 토폴로지 에뮬레이션, SIMD 벡터화 DSP 커널.
- ⚙️ **하드웨어 엔지니어링**: STM32H7 및 Raspberry Pi RP2040 마이크로컨트롤러 기반 베어메탈(Bare-Metal) 오디오 시스템.
- 📐 **엔지니어링 철학**: 핫 루프(Hot Loop) 내에서는 락프리(Lock-Free)와 제로 얼로케이션(Zero-Allocation)을 철저히 고수합니다. 오디오 버퍼 언더런(xrun)은 어쩔 수 없는 타협이 아닌 해결해야 할 명백한 버그입니다.
- ☕ **화면 밖의 일상**: 1970년대 릴 테이프 레코더 수집, 오픈 릴 기계 부품 캘리브레이션, 디스크리트 아날로그 프리앰프 회로 설계.

## 🚀 주요 오픈소스 프로젝트

### 1. `resonant-core` (C++20 / SIMD / CLAP)
결정론적 실시간 신호 처리를 지향하는 모듈형 헤더 온리 오디오 DSP 라이브러리.
- 4x/8x 폴리페이즈 오버샘플링 필터 및 비선형 아날로그 래더 필터 토폴로지 구현.
- 처리 블록 내부 메모리 할당이 전혀 없는 순수 AVX2 및 ARM NEON 내장 함수(Intrinsics) 가속.
- 벤치마크: AMD Zen 4 아키텍처 환경에서 64 샘플 블록당 0.18 마이크로초 소요.

### 2. `reel-flutter` (Rust / WebAssembly / VST3)
자기 테이프의 자기 포화(Saturation) 현상과 캡스턴 모터의 기계적 플러터(Flutter)를 연속 시간으로 에뮬레이션한 오디오 프로세서.
- 4차 룽게-쿠타(RK4) 미분방정식 솔버 기반 자화 히스테리시스 물리 모델링.
- 별도 설치 없이 브라우저에서 바로 음향 특성을 테스트할 수 있는 WebAssembly 크로스 빌드 지원.

### 3. `rp-mpe-engine` (Embedded Rust / RP2040)
MIDI 다성부 표현(MPE, MIDI Polyphonic Expression)을 완벽히 지원하는 자작 하드웨어 전용 베어메탈 신시사이저 펌웨어.
- 듀얼 코어 분할 운용: 코어 0은 USB/DIN-MIDI 패킷 파싱, 코어 1은 48kHz 16보이스 감산 합성 엔진 전담.
- RTOS 오버헤드 없이 스테레오 24비트 I2S DAC으로 다이렉트 DMA 버퍼 스트리밍 전송.

### 4. `ascii-spectrogram` (C99 / 터미널 CLI)
터미널 환경에서 ANSI 트루컬러로 60 FPS 실시간 오디오 워터폴을 렌더링하는 고성능 CLI 분석 도구.
- ALSA, PulseAudio, PipeWire, CoreAudio 스트림에 직접 연결되는 락프리 링 버퍼 탑재.
- 한(Hann), 블랙맨-해리스(Blackman-Harris) 윈도우 함수를 순수 SIMD 명령어로 병렬 가속 연산.
