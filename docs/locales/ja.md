## 🧭 プロフィール

リアルタイム・デジタルオーディオシステムの設計、計測、最適化を専門としています。オーディオレンダリングスレッド内での動的メモリ確保（アロケーション）を徹底的に排除し、ナノ秒精度の決定論的タイミングを保証する超低遅延パイプラインの構築に注力しています。

- 🎛️ **主要専門領域**: リアルタイム物理モデリング音源合成、アナログフィルタ構造のエミュレーション、SIMD最適化DSPカーネル。
- ⚙️ **ハードウェア開発**: STM32H7およびRaspberry Pi RP2040マイコンを対象としたベアメタル（Bare-Metal）オーディオ開発。
- 📐 **技術的信条**: ホットループ（Hot Loop）内ではロックフリーかつゼロアロケーションを厳守すること。オーディオのバッファアンダーラン（xrun）は妥協ではなく、解消すべき明白なバグです。
- ☕ **スクリーン外の日常**: 1970年代のオープンリール式テープレコーダーの収集、機構部の精密キャリブレーション、ディスクリート・アナログプリアンプの回路設計。

## 🚀 主なオープンソースプロジェクト

### 1. `resonant-core` (C++20 / SIMD / CLAP)
決定論的リアルタイム処理を志向したモジュール型ヘッダーオンリー・オーディオDSPライブラリ。
- 4x/8xポリフェーズ・オーバーサンプリングフィルタおよび非線形アナログラダーフィルタ回路を実装。
- 処理ブロック内でのメモリ確保が一切発生しない純粋なAVX2およびARM NEON組込み関数（Intrinsics）による高速化。
- ベンチマーク: AMD Zen 4アーキテクチャにて64サンプルブロックあたり0.18マイクロ秒を達成。

### 2. `reel-flutter` (Rust / WebAssembly / VST3)
磁気テープの磁気飽和現象とキャプスタン駆動部の機械的フラッターを連続時間領域で再現したエミュレータ。
- 4次ルンゲ＝クッタ法（RK4）微分方程式ソルバーに基づく磁気ヒステリシスの物理モデリング。
- インストール不要でブラウザ上から音響特性を検証できるWebAssemblyへのクロスコンパイルに対応。

### 3. `rp-mpe-engine` (Embedded Rust / RP2040)
MIDIポリフォニック・エクスプレッション（MPE）をフルサポートする自作ハードウェア向けベアメタル・シンセサイザー・ファームウェア。
- デュアルコアの明確な役割分離: Core 0がUSB/DIN-MIDI解析を、Core 1が48kHz/16ボイスの減算合成エンジンを担当。
- RTOSのオーバーヘッドを排除し、ステレオ24bit I2S DACへDMAダイレクト転送を実施。

### 4. `ascii-spectrogram` (C99 / ターミナルCLI)
ターミナル上でANSIトゥルーカラーによる60 FPSリアルタイム・オーディオウォーターフォールを描画するCLIツール。
- ALSA、PulseAudio、PipeWire、CoreAudioストリームに直結するロックフリー・リングバッファ構造。
- ハミング窓、ブラックマン・ハリス窓などの窓関数をSIMD並列演算で最適化。
