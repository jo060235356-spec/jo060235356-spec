## 🧭 Обо мне

Я проектирую, тестирую и оптимизирую цифровые аудиосистемы реального времени. Моя основная специализация — конвейеры обработки звука со сверхнизкой задержкой, где динамическое выделение памяти в потоке рендеринга строго запрещено, а детерминированность временных интервалов не подлежит компромиссам.

- 🎛️ **Ключевой фокус**: Синтез на основе физического моделирования, эмуляция схемотехники аналоговых фильтров и SIMD-векторизованные ядра DSP.
- ⚙️ **Аппаратные платформы**: Встраиваемое аудио (bare-metal) на микроконтроллерах STM32H7 и Raspberry Pi RP2040.
- 📐 **Инженерный принцип**: Неблокирующий код (lock-free) и полное отсутствие аллокаций в горячем цикле (hot loop). Прерывания буфера звука (xruns) — это критические баги, а не допустимые издержки.
- ☕ **Вне экрана**: Коллекционирование катушечных магнитофонов 1970-х годов, точная юстировка лентопротяжных механизмов и проектирование дискретных аналоговых предусилителей.

## 🚀 Ключевые проекты с открытым исходным кодом

### 1. `resonant-core` (C++20 / SIMD / CLAP)
Модульная библиотека алгоритмов цифровой обработки аудио (header-only) для строго детерминированного исполнения.
- Включает 4x/8x полифазные фильтры передискретизации и нелинейные аналоговые лестничные фильтры.
- Нативные интринсики AVX2 и ARM NEON с нулевым выделением памяти внутри блоков обработки.
- Производительность: 0.18 микросекунды на блок из 64 сэмплов на микроархитектуре AMD Zen 4.

### 2. `reel-flutter` (Rust / WebAssembly / VST3)
Моделирование в непрерывном времени магнитного насыщения ленты и механической детонации тонвала (flutter).
- Физическое моделирование гистерезиса магнитного сердечника с использованием методов Рунге — Кутты 4-го порядка (RK4).
- Скомпилировано в WebAssembly для мгновенного тестирования акустических алгоритмов прямо в браузере без установки.

### 3. `rp-mpe-engine` (Embedded Rust / RP2040)
Прошивка синтезатора (bare-metal) для кастомного аппаратного обеспечения с полной поддержкой MIDI Polyphonic Expression (MPE).
- Распределение по ядрам: Ядро 0 обрабатывает пакеты USB/DIN-MIDI, Ядро 1 выполняет 16-голосный субтрактивный синтез на частоте 48 кГц.
- Прямая передача через DMA на 24-битный стерео ЦАП I2S без задержек и накладных расходов RTOS.

### 4. `ascii-spectrogram` (C99 / Терминальный CLI)
Высокопроизводительная утилита для визуализации спектрограммы звука в реальном времени (60 FPS) в терминале с поддержкой ANSI Truecolor.
- Неблокирующий кольцевой буфер с прямым подключением к потокам ALSA, PulseAudio, PipeWire и CoreAudio.
- Оконные функции (Ханн, Блэкман-Харрис), полностью оптимизированные через векторные инструкции SIMD.
